## 一、 本次改动的核心价值与实盘意义

### 1.1 痛点解决与量化机理突破

| 维度 | 旧版传统量化系统 (Legacy) | 下一代动态自适应系统 (NextGen) | 用户实盘核心价值 |
| :--- | :--- | :--- | :--- |
| **信号滞后性** | 静态 SMA 均线金叉存在 **2~5 天群延迟**，经常“买在反弹高位、卖在波段底部”。 | 引入 **RSRS (阻力支撑相对强度)** + **KAMA (自适应均线)**，提取盘中最高/最低价博弈斜率。 | **信号领先 2~4 个交易日确认拐点**，买点更从容，利润空间更厚。 |
| **震荡市磨损** | 单只 ETF 全年约 70% 时间处于无趋势震荡，均线频繁在箱体顶底“假突破买入/假跌破卖出”，反复割肉。 | 升级为 **全市场多资产截面动量轮动 (Cross-Section Rotation)** + 效率比动态平滑。 | **不再死磕单只震荡标的**，资金永远聚焦全市场最强赛道；震荡期 KAMA 自动钝化过滤假突破。 |
| **系统性大跌** | 单品种择时无法抵御全市场系统性暴跌（如 2022-2023 持续下行）。 | 内置 **国债 ETF (`511090`) 自动避险切换机制**。 | 当全市场板块均处于破位下行时，**自动全仓切换至 30年国债 ETF 避险生息**，化被动挨打为主动态收益。 |
| **宏观认知孤岛** | 策略封闭运行，完全无视美债利率飙升、汇率大幅贬值、全市场跌多涨少等宏观风险。 | 深度打通 `webhtml` **宏观流动性状态机闸门 (Macro Regime)**。 | 动态根据汇率/美债/市场情绪控制**总仓位上限 (100% / 60% / 30% / 0%)**，有效规避宏观黑天鹅。 |
| **止损与止盈** | 跌破长期均线被动离场，利润大幅回吐。 | **ATR 动态移动追踪止损 (Trailing Stop)**，随价格创新高单调上移。 | **严格保护本金，锁定波段浮盈**，单笔交易最大风险完全可量化、可控制。 |

## 二、 系统架构与新增模块全景

```
guPiaoJiaoYi/
├── quant/                         # 下一代核心量化引擎
│   ├── factors/                   # 1. 低滞后因子层

│   │   ├── kama.py                # KAMA 考夫曼自适应均线（效率比ER与动态平滑）
│   │   └── volatility.py          # ATR 真实波幅、Donchian 突破通道、风险调整动量
│   ├── rotation/                  # 2. 多资产截面轮动层
│   │   ├── universe.py            # 核心 ETF 监控池定义（科技/消费/金融/军工/恒生/国债）
│   │   ├── scorer.py              # 截面复合评分器 (Return/ATR + RSRS + 量比)
│   │   └── engine.py              # 截面决策引擎 (Top 2 轮动 + 缓冲带 + 国债避险切换)
│   ├── regime/                    # 3. 宏观流动性状态机
│   │   └── macro_regime.py        # 离岸汇率/美债10Y/全市场涨跌比 -> 动态总仓位上限
│   ├── risk/                      # 4. 动态风控层
│   │   └── trailing_stop.py       # ATR 移动追踪止盈止损器 (单调上移锁定收益)
│   └── backtest/                  # 5. 回测与评估系统
│       ├── single_asset.py        # 单标的自适应策略回测与新旧对比
│       └── portfolio.py           # 多资产截面轮动组合全历史回测
├── etf_rotation.py                # 截面动量轮动 CLI 命令行工具
├── run.py                         # 统一调度入口（支持 rotation / nextgen / compare 模式）
├── autoProcess.py                 # 自动化流程（接入宏观状态机与 ATR 止损位）
└── tests/
    └── test_quant_engine.py       # 自动化单元测试套件
```

## 四、 实盘操作纪律与最佳实践建议

1. **宏观闸门定仓位，截面排名选标的**：
   * **进攻状态**（全市场涨跌比良好、宽基处于多头）：持有 Top 2 进攻 ETF，总仓位可达 80%~100%；
   * **震荡状态**：总仓位控制在 40%~60%；
   * **防守/避险状态**：进攻标的降仓或清仓，配置 **30年国债 ETF (`511090`)** 或现金。
2. **严格执行 ATR 移动止损**：
   * 买入后，每日关注系统建议的 `建议移动止损位`；
   * 随着价格上涨，止损线自动上移锁定浮盈；一旦收盘价跌破该位置，果断平仓或减仓，绝不扛单。
3. **遵循定期调仓节奏，避免日内频繁频繁买卖**：
   * 截面轮动系统内建了**持仓缓冲带机制**，建议以 **每周（3~5个交易日）** 为周期进行权重再平衡，降低交易佣金与冲击成本。
